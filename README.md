# sanghyang00.github.io

Personal site for Sangmin Lee. Plain HTML, CSS, and a few lines of JavaScript. No theme and no build step.

| Page | File |
| --- | --- |
| About | `index.html` |
| Publications | `publications/index.html` |
| More About Me | `more-about-me/index.html` |
| News | `news/index.html` |
| CV | `cv/index.html` |

`_bibliography/papers.bib` is the publication source. The homepage and publications page load it in the browser, so editing an entry and refreshing is enough. Set `selected` to `true` to show a paper under Selected Publications.

Preview locally:

```bash
python3 -m http.server 8000
```
